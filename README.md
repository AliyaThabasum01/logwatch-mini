# 📊 LogWatch Mini

A lightweight Python CLI tool that analyzes log files and summarizes errors, warnings, and information messages.

## Features

- Count total log lines
- Detect errors
- Detect warnings
- Count information messages
- Simple CLI interface
- No external dependencies

## Run

```bash
python main.py
```

## Example

```text
📊 LogWatch Report
===================================

Total lines : 7
Errors      : 1
Warnings    : 2
Info        : 4
```

## Built With

- Python
- File I/O
